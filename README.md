# 🦉 Duolingo Helper

Userscript для Tampermonkey — расширение для Duolingo с проверкой взаимных подписок, разметкой пользователей и инструментами для работы с друзьями. Окно в стиле Windows XP, плашки на профилях, свои метки.

> Версия: 0.11.6 | Работает на `*.duolingo.com`

## Установка

**Шаг 1.** Установи расширение Tampermonkey для своего браузера:

- [Chrome / Edge / Opera](https://www.tampermonkey.net/)
- [Firefox](https://www.tampermonkey.net/?browser=firefox)

**Шаг 2.** Нажми кнопку ниже чтобы установить скрипт:

[![Установить скрипт](https://img.shields.io/badge/Установить-Tampermonkey-green?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/Vidrimers/Duolingo-helper/refs/heads/master/duo-helper.user.js)

## Функции

### Окно в стиле Windows XP

Панель скрипта выглядит как классическое окно Windows XP (Luna): синяя градиентная шапка, серая рамка, кнопки «свернуть/закрыть».

- Окно **перетаскивается за шапку** в любое место страницы
- Позиция запоминается после перетаскивания и восстанавливается при перезагрузке
- Кнопка **«Сброс»** в настройках возвращает окно на место по умолчанию

**Темы** — в настройках:

| Тема               | Вид                                                  |
| ------------------ | ---------------------------------------------------- |
| **Win95** (дефолт) | Классика: серый `#C0C0C0`, синяя шапка, 3D-кнопки    |
| **WinXP**          | Luna: синяя шапка, серый корпус `#ECE9D8`            |
| **Vista**          | Aero: стеклянная шапка, светлый фон, скругления      |
| **Win11**          | Fluent / Mica: белый фон, Segoe UI, скругления 8px   |
| **Material 3 Light** | Google M3 Expressive: фиолетовые акценты, пилюли, 12–28px |
| **Material 3 Dark**  | Google M3 Expressive тёмный: те же роли, инверсия тонов  |
| **MacOS**          | Металл, светофор 🔴🟡🟢, Helvetica, скруглённые углы |
| **iOS old**        | iOS 6: глянцевые градиенты, пинстрипы, скруглённое   |
| **iOS Liquid Glass** | Apple Liquid Glass: стекло, blur, градиент, блики        |
| **Die my Darling** | Кроваво-красный: тёмный фон, красные акценты, готика |

В шапке окна: **`?`** — описание скрипта и функций, **`🐞`** — багрепорт в GitHub Issues (шаблон уже заполнен). В футере: **«Поддержать проект»** и **«Лицензия»**.

### Проверка подписки на профиле

При открытии страницы пользователя (`/profile/имя`) скрипт автоматически проверяет, подписан ли этот человек на тебя в ответ.

Плашка вставляется **прямо в вёрстку рядом с именем** пользователя (как в URL профиля) и является частью шапки профиля — прокручивается вместе с именем.

- ✅ **Подписан(а) на вас** — зелёная
- ❌ **Не подписан(а) на вас** — красная
- ⏳ Проверка…

Если имя на странице найти не удалось — плашка временно показывается в углу экрана. Клик по плашке открывает панель управления.

### Метки на людей

Во вкладке **«Проверка»** блок **«Метки»** — текст, цвет, заметка для текущего профиля. Рядом ссылка **«Люди с метками»** со списком и кнопкой **«← Назад»**.

| Что                | Описание                                           |
| ------------------ | -------------------------------------------------- |
| ✏ в друзьях        | Добавить/изменить метку из списка друзей (модалка) |
| Метки в «Проверке» | Форма для текущего профиля: текст, цвет, заметка   |
| Люди с метками     | Список всех меток, клик — профиль                  |
| На профиле         | Метка показывается рядом со статусом подписки      |

Метка привязана к `userId` — переживает смену имени и username. В «Изменениях» пишется, если пользователь сменил имя или username.

### Список друзей

Вкладка **«👥 Друзья»**:

| Что                                   | Описание                                                                                                             |
| ------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Обновить                              | Тянуть following + followers, сшить по userId                                                                        |
| Фильтры                               | Все / ❌ не подписаны / ✅ взаимно / 📊 активность                                                                     |
| Активность                            | Streak, XP, дни без активности + сортировка (XP / дни / имя). Без кнопок действий у строк                            |
| Поиск                                 | По имени и username                                                                                                  |
| Проверить активность                  | Опрос подписок ∪ подписчиков (порог в настройках)                                                                    |
| Отписаться / заблокировать неактивных | Массовые действия в «Активности», с учётом исключений 🛡                                                             |
| Отписаться                            | Кнопка у каждого друга                                                                                               |
| Отписаться от неподписанных ❌         | Массовая отписка от тех, кто не подписан на тебя                                                                     |
| Отписаться от всех                    | Тихая ссылка в «Все»: отписка от всех подписок (двойное подтверждение, исключения 🛡 не трогаются)                   |
| История                               | Список действий + «Вернуть» (undo)                                                                                   |
| Изменения                             | Кто подписался / отписался / сменил имя. Красный счётчик новых; новые строки подсвечены, наведение снимает подсветку |
| Исключения                            | 🛡 щит — не трогать при массовых операциях; счётчик                                                                  |
| Блоки                                 | Локальный блок-лист: разблокировка, счётчик                                                                          |

`✅` — человек подписан на тебя в ответ. `❌` — нет. Каждая отписка пишется в историю, её можно вернуть.

### Ручная проверка

В панели (кнопка 🦉 → вкладка **«Проверка»**) можно ввести любой username и проверить его, не заходя на профиль. Там же:

- статус текущего профиля
- строка кнопок: **«Перепроверить»** (сбрасывает кеш) · **«Копировать»** · **«Обновить»** (перезагрузка страницы)
- карточка с твоим аккаунтом (username + id)

Вкладка **«Настройки»**:

| Параметр                      | Описание                                                         |

| Показывать бейдж              | Плашка рядом с именем на профиле                                 |
| Стартовое состояние           | Помнить последнее / Закрыто / Свёрнуто / Раскрыто                |
| Тема окна                     | Win95 / WinXP / Vista / Win11 / M3 Light / M3 Dark / Liquid Glass / MacOS / iOS old / Die my Darling |

### Обновления

Скрипт тихо проверяет GitHub на наличие новой версии (не чаще раза в сутки). Если обновление доступно — вверху панели появится зелёная плашка:

```
🆕 Доступно обновление: v0.2.9 → v0.3.0   [⬆️ Установить]
```

Кнопка **«Установить»** открывает файл для Tampermonkey и **сама перезагружает страницу** через 8 секунд (с отсчётом) — после этого заработает новая версия. Кнопка **«Проверить обновления»** в настройках проверяет вручную.

### Экспорт и импорт

Кнопки находятся **внизу вкладки «Настройки»** (блок «Данные»):

| Кнопка     | Действие                                                                     |
| ---------- | ---------------------------------------------------------------------------- |
| 📥 Экспорт | Модалка: выбор аккаунтов, JWT, шифрование паролем. Файл `duolingo-helper-accounts-{дата}.json` |
| 📤 Импорт  | Формат v2 (мультиаккаунт) и v1 (один аккаунт). Шифрованные JWT — запрос пароля |

**Экспорт** — один файл на все аккаунты. Галочки:
- **Включить JWT** — сохранить токены аккаунтов (для переноса мультиаккаунта)
- **Шифровать паролем** — AES-256-GCM. Без галочки — JWT открытым текстом (с предупреждением)

Пароль не сохраняется нигде — только при экспорте/импорте.

### Облачные сохранения

Блок **«Облачные сохранения»** внизу вкладки «Настройки» — бэкап всех аккаунтов на сервере бота (тот же формат v2, что и экспорт, с JWT). Хранится **один бэкап на аккаунт** (повторное сохранение перезаписывает). Кнопки **«Сохранить»**, **«Восстановить»** и **«Удалить»** доступны только после привязки Telegram; без привязки они заблокированы с подсказкой («Удалить» также заблокирована, пока бэкапа нет). Данные на сервере шифруются (AES-GCM), при отвязке аккаунта бэкап удаляется.

### Защита сердец

Вкладка **«Инструменты»** — блокирует запросы списания сердец при ошибках в уроках (`remove-heart`). Сердца остаются на месте.

- Тумблер **«Блокировать списание сердец»** (по умолчанию включено)
- Работает через перехват `fetch` / `XHR` на странице Duolingo
- **Синхронизация UI**: во время урока счётчик держится равным серверу (локальный минус откатывается), после урока — сверка с API
- Выключается в любой момент, без перезагрузки

> Это защита механики игры в твоём аккаунте, а не накрутка. Но вмешательство в работу сайта формально может нарушать правила Duolingo — на свой страх и риск.

### Уроки

> ⚠️ **Читы. На свой страх и риск.** Укорочение уроков и автосолвер нарушают правила Duolingo. **По умолчанию выключены.**

| Параметр         | Описание                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| Короткие уроки   | `POST /sessions` отдаёт 1–2 простых задания вместо полного урока                               |
| Автосолвер       | Полный: choice, translate, match, tap, cloze, tables, stories, reverse translate, name+article |
| Короткие stories | Убирает вопросы и диалоги из story, остаются только заголовки                                  |
| Решить сейчас    | Принудительно решить текущее задание                                                           |
| Автопрактика     | Решает N уроков подряд (поле количества), кнопки Старт / Стоп                                  |

Автосолвер сам крутится в фоне на `/lesson` и `/practice`, если включён.

Блоки в «Инструментах» — **аккордеон**: открывается один, остальные сворачиваются.

### XP / буст

> ⚠️ **Читы. На свой страх и риск.** Поле — цель в XP (сколько набрать).

| Что      | Описание                                                                             |
| -------- | ------------------------------------------------------------------------------------ |
| Stories  | Накрутка XP через `stories/.../complete` (за раз ~50+ XP)                            |
| Sessions | Накрутка XP через `POST/PUT /sessions` (`UNIT_TEST` + бонусы), проверка по `totalXp` |

## Хранение данных

**Скрипт** — настройки, метки, друзья, история действий и статистика хранятся в хранилище Tampermonkey (`GM_setValue`) — не пропадают при очистке куки и кеша браузера.

**Бот** — после линковки Telegram на сервере бота хранятся: Duolingo ID и имя, TG ID, зашифрованный JWT (AES-GCM), синхронизируемая статистика XP. По мере использования также копятся настройки уведомлений, история массовых действий (для отката в скрипте), результаты проверки активности друзей и багрепорты. JWT хранится только в зашифрованном виде и используется исключительно для запросов к API Duolingo от вашего имени — статистика, лига, накрутки, фоновые уведомления. В логи и в ответы бота он не попадает. При отвязке аккаунта все эти данные удаляются с сервера.

**Экспорт** — формат v2 (мультиаккаунт). JWT включается по желанию; при шифровании паролем сохраняется в виде `jwt_encrypted` (AES-256-GCM, пароль нигде не хранится):

```json
{
  "type": "duolingo-helper-accounts",
  "version": 2,
  "encrypted": true,
  "accounts": [
    {
      "id": "123456",
      "username": "my_username",
      "label": "Основной",
      "data": { "settings": {}, "userTags": {}, "actionLog": [], "stats": {} },
      "jwt_encrypted": { "salt": "…", "iv": "…", "data": "…" }
    }
  ]
}
```
