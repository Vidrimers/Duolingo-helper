# 🦉 Duolingo Helper

Userscript для Tampermonkey — расширение для Duolingo с проверкой взаимных подписок, разметкой пользователей и инструментами для работы с друзьями. Окно в стиле Windows XP, плашки на профилях, свои метки.

> Версия: 0.5.15 | Работает на `*.duolingo.com`

## Установка

**Шаг 1.** Установи расширение Tampermonkey для своего браузера:

- [Chrome / Edge / Opera](https://www.tampermonkey.net/)
- [Firefox](https://www.tampermonkey.net/?browser=firefox)

**Шаг 2.** Нажми кнопку ниже чтобы установить скрипт:

[![Установить скрипт](https://img.shields.io/badge/Установить-Tampermonkey-green?style=for-the-badge&logo=tampermonkey)](https://raw.githubusercontent.com/Vidrimers/Duolingo-helper/refs/heads/master/duo-helper.user.js)

> При открытии ссылки Tampermonkey автоматически распознает скрипт и откроет диалог установки. Нажми **«Установить»**.

**Шаг 3.** Открой [duolingo.com](https://www.duolingo.com) (нужен вход в аккаунт). Слева внизу появится кнопка 🦉.

## Функции

### Окно в стиле Windows XP

Панель скрипта выглядит как классическое окно Windows XP (Luna): синяя градиентная шапка, серая рамка, кнопки «свернуть/закрыть».

- Окно **перетаскивается за шапку** в любое место страницы
- Позиция запоминается после перетаскивания и восстанавливается при перезагрузке
- Кнопка **«Сброс»** в настройках возвращает окно на место по умолчанию

**Темы** — в настройках можно переключить оформление окна:

| Тема | Вид |
| --- | --- |
| **WinXP** | Luna: синяя шапка, серый корпус `#ECE9D8` |
| **Vista** | Aero: стеклянная шапка, светлый фон, скругления |
| **Win95** | Классика: серый `#C0C0C0`, синяя шапка, 3D-кнопки |

### Проверка подписки на профиле

При открытии страницы пользователя (`/profile/имя`) скрипт автоматически проверяет, подписан ли этот человек на тебя в ответ.

Плашка вставляется **прямо в вёрстку рядом с именем** пользователя (как в URL профиля) и является частью шапки профиля — прокручивается вместе с именем.

- ✅ **Подписан(а) на вас** — зелёная
- ❌ **Не подписан(а) на вас** — красная
- ⏳ Проверка…

Если имя на странице найти не удалось — плашка временно показывается в углу экрана. Клик по плашке открывает панель управления.

### Список друзей

Вкладка **«👥 Друзья»**:

| Что | Описание |
| --- | --- |
| Обновить | Тянуть following + followers, сшить по userId |
| Фильтры | Все / ❌ не подписаны / ✅ взаимно / 📊 активность |
| Активность | Streak, XP, дни без активности + сортировка (XP / дни / имя). Без кнопок действий у строк |
| Поиск | По имени и username |
| Проверить активность | Опрос подписок ∪ подписчиков (порог в настройках) |
| Отписаться / заблокировать неактивных | Массовые действия в «Активности», с учётом исключений 🛡 |
| Отписаться | Кнопка у каждого друга |
| Отписаться от неподписанных ❌ | Массовая отписка от тех, кто не подписан на тебя |
| Отписаться от всех | Тихая ссылка в «Все»: отписка от всех подписок (двойное подтверждение, исключения 🛡 не трогаются) |
| История | Список действий + «Вернуть» (undo) |
| Изменения | Кто подписался / отписался. Красный счётчик новых; новые строки подсвечены, наведение снимает подсветку |
| Исключения | 🛡 щит — не трогать при массовых операциях; счётчик |
| Блоки | Локальный блок-лист: разблокировка, счётчик |

`✅` — человек подписан на тебя в ответ. `❌` — нет. Каждая отписка пишется в историю, её можно вернуть.

### Ручная проверка

В панели (кнопка 🦉 → вкладка **«Проверка»**) можно ввести любой username и проверить его, не заходя на профиль. Там же:

- статус текущего профиля
- строка кнопок: **«Перепроверить»** (сбрасывает кеш) · **«Копировать»** · **«Обновить»** (перезагрузка страницы)
- карточка с твоим аккаунтом (username + id)

### Кеш и настройки

Вкладка **«Настройки»**:

| Параметр | Описание |
| --- | --- |
| Автопроверка на профиле | Сам проверять подписку при открытии профиля |
| Показывать бейдж | Плашка рядом с именем на профиле |
| Открывать панель при загрузке | UI раскрыт сразу при заходе на Duolingo (по умолчанию выкл) |
| Тема окна | WinXP / Vista / Win95 |
| Кеш (минут) | Не перезапрашивать API, пока результат свежий (по умолчанию 30) |
| Неактивные, дней | Порог для фильтра «Неактивные» (по умолчанию 3) |
| Задержка между запросами (мс) | Пауза при массовых опросах/операциях (rate limit) |
| Сбросить позицию окна | Вернуть окно XP на место по умолчанию |
| Очистить кеш | Удалить сохранённые результаты проверок |
| Данные | Кнопки **«Экспорт»** и **«Импорт»** JSON |

### Обновления

Скрипт тихо проверяет GitHub на наличие новой версии (не чаще раза в сутки). Если обновление доступно — вверху панели появится зелёная плашка:

```
🆕 Доступно обновление: v0.2.9 → v0.3.0   [⬆️ Установить]
```

Кнопка **«Установить»** открывает файл для Tampermonkey и **сама перезагружает страницу** через 8 секунд (с отсчётом) — после этого заработает новая версия. Кнопка **«Проверить обновления»** в настройках проверяет вручную.

### Экспорт и импорт

Кнопки находятся **внизу вкладки «Настройки»** (блок «Данные»):

| Кнопка | Действие |
| --- | --- |
| 📥 Экспорт | Скачать локальные данные скрипта (профиль, кеш проверок, настройки) |
| 📤 Импорт | Загрузить ранее сохранённый файл: настройки мержатся, кеш заменяется |

Токен в файл не попадает.

### Защита сердец

Вкладка **«Инструменты»** — блокирует запросы списания сердец при ошибках в уроках (`remove-heart`). Сердца остаются на месте.

- Тумблер **«Блокировать списание сердец»** (по умолчанию включено)
- Работает через перехват `fetch` / `XHR` на странице Duolingo
- **Синхронизация UI**: во время урока счётчик держится равным серверу (локальный минус откатывается), после урока — сверка с API
- Выключается в любой момент, без перезагрузки

> Это защита механики игры в твоём аккаунте, а не накрутка. Но вмешательство в работу сайта формально может нарушать правила Duolingo — на свой страх и риск.

### Уроки

> ⚠️ **Читы. На свой страх и риск.** Укорочение уроков и автосолвер нарушают правила Duolingo. **По умолчанию выключены.**

| Параметр | Описание |
| --- | --- |
| Короткие уроки | `POST /sessions` отдаёт 1–2 простых задания вместо полного урока |
| Автосолвер | Полный: choice, translate, match, tap, cloze, tables, stories, reverse translate, name+article |
| Решить сейчас | Принудительно решить текущее задание |

Автосолвер сам крутится в фоне на `/lesson` и `/practice`, если включён.

Блоки в «Инструментах» — **аккордеон**: открывается один, остальные сворачиваются.

### XP / буст

> ⚠️ **Читы. На свой страх и риск.**

| Что | Описание |
| --- | --- |
| Фейк XP-буст (x2) | Подмешивает активный буст в `GET /users` (15/60 мин). UI может показывать множитель |
| Stories | Накрутка XP через `stories/.../complete` (~499 XP за раз) |
| Sessions | Накрутка XP через `POST/PUT /sessions` с `hasBoost` (~110 XP за раз) |

### Квесты

> ⚠️ **Чит. На свой страх и риск.** Инъекция прогресса в квесты через `goals-api.duolingo.com`. Нарушает правила Duolingo, возможна блокировка аккаунта.

Вкладка **«Инструменты»**:

| Кнопка | Действие |
| --- | --- |
| Daily | Закрывает все незакрытые daily-квесты (инъекция метрик) |
| Monthly | Загружает список monthly-квестов с прогрессом |
| Забрать все | Выполняет все незакрытые monthly по очереди |
| GET у квеста | Выполняет один конкретный monthly-квест |

### Магазин

> ⚠️ **Чит. На свой страх и риск.** Выдача предметов магазина через `isFree: true` без списания гемов. Нарушает правила Duolingo.

| Кнопка | Действие |
| --- | --- |
| Загрузить | Список предметов из `/2023-05-23/shop-items` |
| GET у предмета | Выдать предмет бесплатно |
| Super 3 дня | Триал-подписка Super (`immersive_subscription`) |

### Гемы

> ⚠️ **Чит. На свой страх и риск.** Сбор `rewardBundles` (`SKILL_COMPLETION`) через PATCH `/rewards/{id}`. Нарушает правила Duolingo.

**Gems — это алмазы** (премиум-валюта). Кнопки GET в магазине баланс гемов **не** пополняют — для этого есть отдельный блок.

| Кнопка | Действие |
| --- | --- |
| Собрать | Забрать все доступные gem-награды один раз |
| Фарм | Крутить сбор в цикле, пока есть награды |
| Стоп | Остановить фарм |

### Streak

> ⚠️ **Чит. На свой страх и риск.** Накрутка/восстановление дней серии через `POST/PUT /2017-06-30/sessions` с подменой дат. Нарушает правила Duolingo.

| Кнопка | Действие |
| --- | --- |
| Накрутить дни | Создаёт practice-сессии с `endTime` в прошлом (по таймзоне аккаунта) |
| Стоп | Прервать |

Ввод — количество дней (1–365).

### Лига

| Кнопка | Действие |
| --- | --- |
| Таблица | Места, XP, разрыв до тебя, повышение/понижение |
| Вступить | Вступление в недельную лигу |
| Фарм до места | Накрутка XP через stories, пока не выйдешь на место (чит) |
| Стоп | Прервать фарм |

## Планы на будущее

### Топ-3

- Откат / undo-лог для массовых операций — запомнить кого удалил, чтобы можно было вернуть
- Мёртвые друзья — нет активности N дней, массовая чистка
- Свои метки на юзеров: «скамер», «друг», «мёртвый», свой цвет и заметки

### Социалка

- Проверка в полном списке друзей — галочка или крестик у каждого
- Отображение изменений в UI (кто подписался / отписался)
- Массовое удаление из друзей
- Массовое удаление тех, кто не подписан на тебя
- Авто-follow-back
- Кто отписался / кто заблокировал — снапшот-дифф по дням
- Статус streak у друзей
- Блок-лист менеджер

### Обучение и QoL

- Авторешение уроков
- Предотвращение потери сердец
- Статистика: XP за день/неделю, история лиг, графики
- Слежка за лигой — кто обгоняет, за сколько XP оторваться
- Автозабор наград за квесты
- Экспорт словаря и прогресса
- Предупреждение о streak freeze

### Разметка людей

- Метки на профили и друзей: цвет, заметки, категории
- Синхронизация меток между своими скриптами

### Аккаунты

- Мультиаккаунт-переключатель
- Дашборд: XP, streak, лиги всех аккаунтов в одной таблице

### Безопасность

- Рандомные задержки между запросами
- Undo-лог для отката массовых действий

## Хранение данных

Данные хранятся в хранилище Tampermonkey (`GM_storage`) — не пропадают при очистке куки и кеша браузера.

Структура JSON при экспорте:

```json
{
  "settings": {
    "autoCheck": true,
    "showBadge": true,
    "cacheMinutes": 30
  },
  "followCache": {
    "username": {
      "followsMe": true,
      "theirId": "123456",
      "theirName": "Name",
      "checkedAt": 1700000000000
    }
  },
  "me": {
    "id": "123456",
    "username": "my_username"
  }
}
```

> ⚠️ API Duolingo — неофициальный. Массовые действия (удаление, отписка) вводятся аккуратно и с рандомными задержками. JWT-токен никуда не отправляется.
